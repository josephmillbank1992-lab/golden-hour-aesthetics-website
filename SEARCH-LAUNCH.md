# Search launch

The intended canonical domain is https://goldenhouraesthetics.co.uk. The site is currently a preview, so indexing is disabled. Once that domain serves the website, set SITE_INDEXABLE=true in the production hosting environment and rebuild. Leave it unset in preview environments. Confirm redirects, robots.txt, sitemap.xml and rendered canonical tags on the custom domain, then submit the sitemap in Search Console.
