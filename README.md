# Golden Hour Aesthetics website

A one-page marketing website for Golden Hour Aesthetics by Jess in Darley Abbey, Derby.

The website is deliberately separate from the booking platform. It introduces the clinic, treatments and brand, then sends clients to a configurable external booking URL. Prices, deposits, appointment lengths and live availability belong in the booking platform and should not be duplicated here.

## Run the website locally

1. Install the project dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env.local`.

3. Add any available booking, social and Google review links to `.env.local`.

4. Start the development website:

   ```bash
   npm run dev
   ```

5. Open `http://localhost:3000`.

## Where to update each part

### Booking URL

Set `NEXT_PUBLIC_BOOKING_URL` in `.env.local`:

```text
NEXT_PUBLIC_BOOKING_URL=https://your-booking-platform.example.com
```

Until this is set, booking buttons open a pre-addressed email enquiry and the hero clearly says that online booking is being prepared. This avoids presenting the booking platform as live before it is ready.

The fallback behaviour and button wording are in `src/content/site-config.ts`.

### Social links

Set these values in `.env.local`:

```text
NEXT_PUBLIC_INSTAGRAM_URL=https://www.instagram.com/your-profile
NEXT_PUBLIC_FACEBOOK_URL=https://www.facebook.com/your-page
```

Social links only become clickable when a URL is supplied. The configuration is read in `src/content/site-config.ts`.

### Google review links

Set these values in `.env.local`:

```text
NEXT_PUBLIC_GOOGLE_REVIEWS_URL=https://...
NEXT_PUBLIC_GOOGLE_REVIEW_FORM_URL=https://...
```

The first URL is for reading existing reviews. The second is the direct “write a review” link. The review buttons stay hidden until these URLs are supplied.

The three review cards currently contain clearly labelled placeholder wording. Replace them with approved, genuine client reviews before launch in `src/content/site-content.ts`.

### Main copy, treatments and contact details

Edit `src/content/site-content.ts` for:

- business name, phone, email, address and map link;
- navigation labels;
- treatment names and descriptions;
- “Why Golden Hour” points;
- approved client review copy.

Longer page sections, including the introduction and Jess’s biography, are in `src/app/page.tsx`. Search for the visible sentence you want to change, then edit the surrounding paragraph.

### Images

Website images live in `public/images`.

- `public/images/golden-hour-logo.png` is the current Canva logo reference.
- The “Meet Jess” area is intentionally a styled placeholder. Replace the placeholder inside the `about` section in `src/app/page.tsx` with an approved portrait using Next.js `Image`.
- The before-and-after cards are styled placeholders. Replace them only with approved client photography and recorded consent.

When adding a photo, keep a descriptive `alt` value unless the image is purely decorative.

### Brand colours and typography

Brand colours are CSS variables at the top of `src/app/globals.css`:

```css
--ink: #241722;
--aubergine: #4b203b;
--wine: #6d2748;
--amber: #f4a43b;
--gold: #ffc45d;
--paper: #fff9ef;
```

The heading and body fonts are configured in `src/app/layout.tsx`. The current combination uses Manrope for bold graphic typography and DM Mono for the precise, clinical supporting copy.

### SEO details

Page title, description, canonical URL and social-sharing metadata are in `src/app/layout.tsx`.

Local business structured data is in `src/app/page.tsx`. Search for `structuredData` if the address, phone number or business details change.

Search-engine files are generated by:

- `src/app/robots.ts`
- `src/app/sitemap.ts`

## Content and compliance notes

- Do not use “nurse-led aesthetics” or describe Jess as a registered nurse until that status is accurate and approved for publication.
- Keep the current wording that Jess is completing her BSc (Hons) in Adult Nursing.
- Avoid promises or guarantees about treatment outcomes.
- Use only genuine reviews and consented client photography before launch.
- Keep treatment suitability subject to consultation.
- Do not place prices, deposits, durations or live availability on this marketing website.

## Checks before launch

Run these after making changes:

```bash
npm run lint
npm run build
```

Then review the full page on a phone and desktop, test every link, and confirm all public wording with Jess.
